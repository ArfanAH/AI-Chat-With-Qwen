1. PROJECT OVERVIEW
===================

This project is a local AI chat application.

The application allows users to:
- Chat with a local AI model
- Have multiple conversations
- Store conversations locally
- Rename conversations
- Delete conversations
- Stop AI generation
- Regenerate AI responses
- Stream AI responses
- Use Markdown formatting
- Display code blocks
- Use the application on desktop and mobile

Used for:
- Deleting a conversation


15. CHAT FEATURES
=================

Normal message:
- User sends message
- Frontend sends conversation history to FastAPI
- FastAPI sends request to Ollama
- Ollama generates response
- Response is streamed to frontend
- Completed response is saved to SQLite


Regenerate:
- Existing assistant response is removed
- Latest user message is sent again
- New AI response is generated
- New response is saved


Stop generation:
- Uses AbortController
- Stops frontend streaming request
- Incomplete assistant response is not saved

26. TROUBLESHOOTING
===================

If AI does not respond:
- Check that Ollama is running.
- Check that "my-qwen-chat" exists.
- Check that FastAPI is running on port 8000.
- Check browser console for frontend errors.

If frontend does not start:
- Run npm install.
- Check Node.js version.
- Run npm run build to identify production build errors.

If database history disappears:
- Check that backend/data/chat.db still exists.

If model is missing:

ollama list

Then recreate if necessary:

ollama create my-qwen-chat -f "E:\React\Modelfile"


27. PROJECT GOAL
===============

The goal of this project is to provide a private, local,
responsive AI chat application using a locally running Qwen
language model through Ollama.

The application is designed to work without depending on
cloud-based AI APIs for normal chat operations.
